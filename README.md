# 🧮 Calculadora C# (WinForms)

Uma calculadora moderna desenvolvida em **C# com Windows Forms**, com foco em **interface intuitiva** e **visual escuro**.  
Projeto criado como prática de lógica, interface gráfica e eventos no .NET.

---

## 🚀 Funcionalidades

- Operações básicas: **soma (+)**, **subtração (-)**, **multiplicação (×)** e **divisão (÷)**
- Botões estilizados e responsivos
- Interface limpa e organizada
- Exibição do histórico da operação atual
- Botão **C (Clear)** para limpar a tela
- Suporte a números decimais
- Suporte para receber inputs do teclado numerico

## 🧰 Tecnologias Utilizadas

- **Linguagem:** C#  
- **Framework:** .NET Framework / Windows Forms  
- **IDE:** Visual Studio
